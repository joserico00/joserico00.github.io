The project

A tool that downloads a track, finds the beat grid, and renders a gapless Ogg loop for Foundry Virtual Tabletop, from either a GUI or the command line.

Implementation and context

Game masters want ambient music that loops without a click. yt2ogg processes audio in float32, normalizes with constant gain, tracks beats with a dynamic-programming grid written in pure NumPy, and cuts on the grid so the loop point lands on a downbeat. A Tk GUI and a CLI share the same pipeline, and a build script that finds its own Python produces standalone executables with self-tests on any machine, not just the one it was written on.
