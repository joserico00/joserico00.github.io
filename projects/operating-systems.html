The project

Course projects covering a socket-based distributed file system with a metadata server and data nodes, page-replacement algorithms, and a thread scheduling simulation.

Implementation and context

The distributed file system splits files into blocks across data nodes and tracks them in a metadata server. Companion projects implement FIFO, optimal and WSClock page replacement and a multi-threaded scheduler with simulated devices.
