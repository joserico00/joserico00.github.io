The project

A resumable ingestion pipeline that pulls video-game metadata from IGDB, enriches it with HowLongToBeat playtimes, and exports clean CSVs for database import.

Implementation and context

Built for the 1UPPER software-engineering project, the pipeline handles rate limits with backoff, walks IGDB with keyset pagination, checkpoints progress so interrupted runs resume, and writes its cache atomically. A lookup that could not be reached is treated as unknown rather than a confirmed miss, so the next run retries it. Credentials come from the environment, tests cover the parsing, and the README includes a responsible-use section.
