The project

A Docker-based Tor SOCKS proxy and Python scripts for finding keyword matches and checking whether .onion links respond.

Implementation and context

Researchers monitoring mentions of a region or organization on hidden services need a repeatable, isolated way to test links. The proxy runs in Docker, the checker routes every request through it, caches links already visited, and writes matches for the keyword list to a results file.
