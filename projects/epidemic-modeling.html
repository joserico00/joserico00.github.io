The project

Teaching notebooks that build an SIR epidemic model in pure NumPy, run stochastic ensembles, and check results against committed reference metrics.

Implementation and context

Two group tracks and a master notebook take students from a single-day SIR step to full simulations with seeded synthetic data. A small helper module, an environment file, expected output figures and a reference metrics file make every run reproducible, and an HTML preview lets readers see the results without opening Jupyter. Nineteen offline checks confirm the generator still reproduces the committed reference metrics and that the fitted R0 has not drifted.
