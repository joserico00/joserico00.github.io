NETWORK DEFENSE + RESEARCH SOFTWARE

Making network defense accessible

NVSRCO connects remote networks to a central analysis server for host discovery, vulnerability assessment, and secure reporting.

MY ROLE

Graduate Researcher & Software Developer

ORGANIZATION

University of Puerto Rico · Río Piedras

WHEN

August 2022 – December 2025

The problem

Organizations with limited security budgets still need to know which systems are on their networks, what services those systems expose, and which vulnerabilities require attention. NVSRCO brings those tasks together in a platform built on open-source components.

What I built

I designed and implemented an end-to-end network situational-awareness and vulnerability-scanning system. It combines host discovery, port and service enumeration, vulnerability assessment, persistent scan storage, and web reporting.

Remote client networks connect to a central analysis server over OpenVPN. Python integrates Nmap and OpenVAS for scanning, SQLite for stored findings, and Flask for presenting results for visualization and triage.

Remote client network→OpenVPN→Central analysis server→Stored findings & web reports

Implementation

  • Discovery: identify live hosts and enumerate exposed ports and services.
  • Assessment: run vulnerability scans and collect findings.
  • Persistence: store results in SQLite for later review.
  • Reporting: present findings through a central web application.
  • Remote access: connect client networks through VPN links.
Open-source components throughout

The platform was designed for organizations with limited budgets, with the analysis server as the core infrastructure cost. Vulnerability scans took approximately 30 minutes in the project context; duration depends on the network and scan configuration.

Research output

The project produced working software and a graduate technical report published in the University of Puerto Rico institutional repository. The source code and report provide a closer look at the implementation and research.
