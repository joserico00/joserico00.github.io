The project

A desktop app where elders post help requests and nearby caregivers find them by distance, built in a weekend for Bloomberg's hackathon at UPRRP.

Implementation and context

Built for Bloomberg’s 2022 hackathon at UPR Río Piedras, Seniory connects older adults requesting help with nearby caregivers or volunteers. The desktop prototype uses Python, PySimpleGUI, SQLite, and geopy to store requests and sort them by distance. The project placed fifth; the published repository includes setup instructions and demo IDs.
